# DINO RUSH: 공룡 협곡 롤러코스터 (3D / 카드보드 VR)

공룡이 열차를 덮치는 롤러코스터입니다. 브라우저에서 바로 돌아가는 Three.js(WebGL) 3D 게임이고, 설치할 것은 없습니다.
모든 모델, 텍스처, 소리는 코드로 직접 생성합니다. 외부 이미지·사운드 파일은 쓰지 않습니다.

## 실행

1. 이 폴더(`dino-coaster/`)를 HTTPS로 서비스합니다. 예: GitHub Pages
   (저장소 Settings → Pages → 브랜치 선택 → `/dino-coaster/` 경로로 접속)
2. 로컬에서 테스트하려면:
   ```
   cd dino-coaster
   python3 -m http.server 8000
   ```
   PC에서 `http://localhost:8000` 접속
   (휴대폰 자이로 센서는 **HTTPS**에서만 동작합니다)

## 카드보드 VR

- 휴대폰으로 접속 → **카드보드 VR 탑승** → 가로로 돌려 카드보드에 끼우기
- 화면이 양쪽 눈용으로 나뉘고(IPD 64mm), 카드보드 렌즈에 맞춘 배럴 왜곡 보정이 들어갑니다
- 고개를 돌리면 자이로로 360° 시점이 움직입니다. 화면을 두 번 탭하면 정면이 재설정됩니다
- 도착하면 약 9초 뒤 자동으로 다시 출발합니다

## 탑승 코스 (약 3분 20초, 트랙 1.7km)

| 구간 | 내용 |
|---|---|
| 체인 리프트 1 (50m) | 화산, 초식공룡 무리, 프테라노돈 급강하 |
| 첫 낙하 → 계곡 | **티라노사우루스 매복**: 포효하며 머리 바로 옆에서 턱을 물고 추격 |
| 강 스플래시 | **스피노사우루스**가 물에서 솟아올라 공격 |
| 리프트 2 | **브라키오사우루스**가 눈높이에서 지켜봄 |
| 평원 | **트리케라톱스** 돌진이 트랙을 가로지름 |
| 나선 헬릭스 → 숲 | **랩터 무리** 병주 추격, 한 마리가 트랙 위로 점프 |
| 암석 터널 | 어둠 속에서 빛나는 눈 |
| 런치 | **카르노타우루스**를 부스터로 따돌림 |
| 마지막 | **거대 티라노**가 길을 막고 서 있고, 그 아래로 통과 |

## 기술 메모

- `js/track.js`: 캣멀롬 트랙, 에너지 보존과 마찰을 쓴 속도 사전 시뮬레이션, 속도에 따른 자동 뱅킹, G-포스 계산
- `js/world.js`: 노이즈 지형, 트랙에 맞춘 협곡 굴착, 강/호수, 하늘 셰이더와 PMREM 환경광, 식생 인스턴싱, 터널, 역사
- `js/creatures.js`: 스켈레톤 스키닝 공룡 8종, 절차적 피부, 보행 사이클, 시선 추적, 턱 애니메이션
- `js/encounters.js`: 공격 연출 스크립트(매복, 수중 기습, 돌진, 추격, 점프)
- `js/audio.js`: WebAudio로 합성하는 포효, 랩터 울음, 바람, 체인 소리, 정글 소리(HRTF 3D 사운드)
- `js/vr.js`: 스테레오 렌더링, 렌즈 왜곡 보정, 자이로 헤드 트래킹

화질: 주소 뒤에 `?q=high` 또는 `?q=low`를 붙이거나 메뉴에서 고릅니다. 프레임이 떨어지면 해상도를 자동으로 낮춥니다.
